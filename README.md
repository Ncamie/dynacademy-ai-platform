# Dynacademy

AI-powered educational and career guidance platform.

## Features
- AI Career Guidance
- APS Calculator
- Educational Analytics

## Technologies
- Python
- Firebase
- Chart.js

## Problem Solved
Dynacademy improves educational accessibility for learners.
